# 2026-09-05

## 修复：做T记录（fund_t_trades）在版本更新时被清空

**现象**：用户反馈做T记录全部消失，K线图紫色标记和 TradeCenter 的 T交易区块都空了。

**根因**：`src/utils/storage.ts` 的 `checkVersionAndClearCache()` 在版本变更时清理缓存：
- 清理规则 = key 命中 `CACHE_PREFIXES`（`fund_`/`api_`/`market_`/`estimate_`）**且不在** `preservedKeys` 白名单
- `T_TRADES = 'fund_t_trades'` 以 `fund_` 开头会命中前缀，但当初加做T功能时（commit 8743b76「标记T」）**漏登记进白名单**
- 结果每次 APP 版本更新，`fund_t_trades` 被 `removeItem` 删掉

**修复**：把 `STORAGE_KEYS.T_TRADES` 加入 `preservedKeys`，并补注释警告「新增存储 key 必须同步白名单」。

**教训/约定**：所有以 `fund_` 等缓存前缀开头的**用户数据** key，必须登记进 `preservedKeys`，否则会被版本更新误删。当前白名单已覆盖：watchlist / holdings / trades / t_trades / net_values / source_filter / app_version / starred_funds。

**验证**：`npx vue-tsc --noEmit -p tsconfig.app.json` 通过，无错误。

**数据恢复提示**：Holding.vue 的本地导出和 GitHub Gist 云端备份都含 `tTrades: getTTrades()`；云端恢复也会在 `jsonData.tTrades` 存在时调用 `saveTTrades(jsonData.tTrades)`。若用户在做T记录被清除前成功执行过云端备份，Gist 理论上可以恢复。之前误判为 Gist 只存持仓，已纠正。
