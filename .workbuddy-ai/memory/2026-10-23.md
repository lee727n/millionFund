## 排查：018388 显示 -2.04% 却无重仓股信息（用户提问，非改码）

结论：**-2.04% 不是估值，是 10-22 已公布的真实净值涨跌**（1.2707，前值 1.2971）。

证据链：
1. `fundgz.1234567.com.cn/js/018388.js` → 返回「页面未找到」，天天基金**无该基金盘中估值**（官方估值只覆盖大部分基金，非全覆盖）。
2. `pingzhongdata/018388.js` → `stockCodesNew=[]`、**`Data_StockPosition` 完全不存在** → `fetchTopHoldings` 返回 0 只 → 本地加权估算路径（`fetchFundEstimateFast` 里的 `weightedChange/totalWeight`）无从算起。
3. 018388 =华泰柏瑞港股通红利ETF联接C，是**ETF 联接基金**：资产是「持有目标 ETF」，不是直接持股，所以天天基金不披露股票持仓明细 —— 这正是用户「看不到任何重仓股」的根本原因。
4. 两条估值路都空 → `fetchFundAccurateData`（fundFast.ts:1738 起）走 `isWeekday && isNavUpdated` 净值分支，`dayChange = navChange = -2.04`，`isNav=true`。

要点：
- **联接基金/FOF 类天然无重仓股**，`fetchTopHoldingsFromApi`（抓 fund.eastmoney.com HTML 的「股票持仓」表）也必然找不到表格 → 双重为空。
- `getFXAdjustment()` 只在 `isQDII` 时叠加**美股**（纳斯达克/标普×0.15）汇率调整，对港股通基金其实是错配（港币汇率未计），但本次因 holdings 为空没走到这步。
- UI 上该数字来自 `holding.todayChange`（`updateHoldingWithAccurateData` 写入，`data.dayChange.toFixed(2)`），`FundGridItem.vue` 直接渲染；QDII 净值 T+1 公布，所以盘中看到的一直是上一交易日涨跌，属预期行为、非bug。
