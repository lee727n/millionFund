## 全景大屏顶栏新增「QD占比 / 定投概览」模块
- 位置：`PanoramaDashboard.vue` 顶部状态栏 `.top-stats` 内，「利润率」与「交易状态」两个 stat-block 之间（flex 行，不额外撑高顶栏）。
- 内容：① 总 QD占比 = 全部账户 QDII 市值 / (总现金 + 总市值)，附 QD市值；② 三账户各自 QD占比 = 该账户 QDII 市值 / (账户现金 + 账户市值)；③ 每账户日均定投额（`planDailyRate` 折算）+ 剩余可投天数 = 账户现金 / 日均额（无计划显示「未设定投」）。
- 实现：`qdDcaStats` / `qdTotal` 两个 computed（依赖 aliHoldings/txHoldings/jdHoldings、accountCash、getDCAPlans）；新增 `fmtRatio`（无正负号）专门给占比用，`fmtPct` 仍给涨跌幅。真实图标取自 `accountIcons`（ali/TX/JD jpg），`@error` 复用 `onLogoError`。
- 验证：`npx vue-tsc -b` 通过；Playwright 注入持仓/现金/定投计划核对数值全部正确（ali QD16.0%/¥500·20天、TX QD32.4%/¥200·25天、JD 0%/未设定投、总 21.6%）。
- 注意：定投计划改于独立 /dca 页，Panorama 内仅靠 accountCash 变化触发重算（刷新时），编辑 DCA 不实时同步属预期。

- 实现：
  - `.top-right` 由 grid 改 flex：`flex-direction:column; align-items:flex-end; gap:6px`；新增 `.top-row`（每行 `display:flex; align-items:center; gap:8px`）。模板拆成 `.top-row-1`（深浅/备份组/tab隐藏）、`.top-row-2`（时钟/操作组/倒计时）。
  - 新增 `.seg` 基类（inline-flex + overflow:hidden + 外框）+ `.seg > *`（去自身 border/radius/bg、`border-right:1px` 连接、`:last-child` 去掉右边框）+ `.seg > .is-on` 蓝色高亮。
  - 备份组：`<div class="seg top-backup-seg"><BackupActions class="top-backup-actions" .../></div>`，靠 `.top-backup-seg > .top-backup-actions { display:contents !important }` 让 van-button 成为 `.seg` 直接子级；`:deep(.van-button.top-text-btn:last-child)` 去右边框（BackupActions 用 `v-if` 隐藏恢复按钮，故 last-child 正确命中「云恢复」）。
  - 操作组：`.top-actions` 内 3 个 `.seg-btn`（星标/自动刷新/刷新）。`.refresh-btn` 原有独立 border/radius/bg 必须删掉（.seg 统一提供，且它定义在文件更靠后、同特异性会覆盖 .seg）。`.auto-refresh-toggle.is-on` 复用 `.seg > .is-on` 蓝色高亮。
  - `.theme-toggle` 补 `height:30px`+`.theme-toggle-btn` 改 flex 居中，与 .seg 同高。
- 验证：`npx vue-tsc -b` 通过；Playwright 实测 `.top-right` 宽 **275px**（原 grid 约 370px→更省）；组间 gap=8px、星标/自动刷新/刷新内部 gap=**0**（flush）、时钟色 rgb(78,168,254)、第2行 clock/actions/countdown mid 完全一致（垂直居中）。附 Eastmoney CORS 报错为取指数噪声，与本改动无关。

## 定投页（DCAPage.vue）增加「行内编辑每期金额」
- 需求：已添加的计划，点击金额可改金额、保存后后续按新金额执行。
- 实现：`.dca-p-amt`（原本 `{{ fmtMoney(plan.amount) }}/期`）改为可点击——点击切到 `editingId===plan.id` 分支，渲染 `<input type="number">` + 保存/取消；`startEdit` 取 `editingId=plan.id, editAmount=plan.amount`，`saveEdit` 校验>0后 `updateDCAPlan(editingId,{amount})` + `dcaRefreshKey++`（强制重算 stat），`cancelEdit` 复位。同一时刻仅一个计划处于编辑态。新增 scoped CSS：`.dca-p-amt:hover` 下划线提示可点；`.dca-edit-input`/`.dca-edit-save`/`.dca-edit-cancel` 风格对齐主按钮。
- 关键：`updateDCAPlan` 走 `saveDCAPlans` 持久化，`computeDCAStats` 的 `dailyRate=ΣplanDailyRate(p)` 会随之刷新（日均展示同步），`executeDueDCAs` 每次都 `getDCAPlans()` 取最新值 → 后续扣款自然用新金额（无需改执行引擎）。
- 验证：`npx vue-tsc -b` 通过；Playwright（seed 1 条 daily 1000 计划）确认 点击金额→输入5000→保存 后 金额文本 ¥5,000.00/期、账户「日均 ¥5,000.00/日」、localStorage `dca_plans` 该计划 `amount===5000`。
