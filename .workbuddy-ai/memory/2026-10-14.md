# 2026-10-14 工作日志

## 星标K线：渲染时序优化 + 左側持仓金额

### 1. 加载慢优化（用户反馈：手机版星标K线要等好久才出来）
- **根因**：`StarKLinePanel.vue` 的 `boot()` 原流程是 `await loadRealtime()`（批量拉当日估值/净值）全部完成后才 `isReady=true`，导致整页图表被「当天估值计算」卡住。
- **修法**：`isReady.value = true` 移到 `await loadRealtime()` **之前**。每张 `MiniKLineChart` 挂载时本就会自己 `fetchSimpleKLineData` 拉历史净值先画出走势，等 `realtime`（估值/净值）到位后通过 `props.realtime` watch 触发重绘补上「今天延伸点」。首屏历史 K 线立即出现，估值后台补。
- `onActivated` 同样：先 `isReady=true`，再 `loadRealtime()`（顺带保持手机页切回前台刷新当日点）。
- 效果：历史 K 线先渲染，估值算完再刷新当日点，不再整页等。

### 2. 手机版第二行左侧加「持仓：金额」
- 新增 `MiniKLineChart` prop `showLeftMarketValue?: boolean`（默认 false）。`drawChart` 在两行头（width<280 && height>=130）模式下，于第二行**左侧**画「持仓：¥xxx」（用 `props.marketValue` + `fmtWan`，≥1万显示 xx万）。
- `StarKLinePanel` 透传该 prop（`showLeftMarketValue`，默认 false）+ 转发到 `MiniKLineChart`。
- `MobileStarKLine.vue` 给 `<StarKLinePanel>` 加 `:show-left-market-value="true"` → 手机页每只基金第二行左侧显示持仓金额，右侧仍显示当日/累计盈亏百分比。

### 3. 校验
- `npx vue-tsc -b` 通过（EXIT 0）。

### 4. 范围说明
- 左側持仓金额目前只在手机版星标页开启；全景大屏第二列若也要左側持仓金额可再开 `showLeftMarketValue`。
- 依赖持仓 `marketValue` 已计算（与页面其它市值同源），估值未刷完时金额可能暂为 0/空，跑完即更新。

## 交易弹窗：新增「清仓」功能（长按→交易）

### 1. 需求
- 原来只有「加仓/减仓」：减仓要自己算金额→份额，麻烦。
- 新增「清仓」：自动按「当前持仓份额 × 成交净值」带出卖出金额，一键卖出全部，且和减仓一样自动在 K 线上标记卖出点。

### 2. 实现（Home.vue + PanoramaDashboard.vue 同步加，两处交易弹窗同款）
- `tradeFormData` 加 `isClear: boolean`（默认 false）。
- 新增 `setTradeType('buy'|'sell'|'clear')`：清仓时 `type='sell' + isClear=true` 并立即 `fillClearAmount()`；`fillClearAmount()` 用 `holdingStore.holdings` 当前份额 × 净值算出金额自动填入。
- `watch([isClear, netValue])`：清仓模式下净值到位（实时估值/历史查找）后自动刷新带出金额。
- 模板：第三张 tab「清仓」；清仓时「交易金额」输入框 `readonly`（提示「清仓金额自动带出」）；预览区显示「清仓份额：X 份（按持仓全额带出）」；确认按钮显示「确认清仓」。
- `submitTrade`：清仓分支用 `shares = 当前持仓份额`、`amount = shares*netValue`、`type='sell'`，更新持有 → `shares=0`；无持仓时提示「当前无持仓份额可清仓」；清仓跳过「份额超持仓」守卫。

### 3. 标记卖出点
- 卖出点由 `MiniKLineChart` 读 `getTradesByCode` 自动绘制（buy=红、sell=绿）。清仓提交的是 `sell` 交易，所以**和减仓一样自动在 K 线标记卖出点**，无需额外代码。

### 4. 校验
- `npx vue-tsc -b` 通过（EXIT 0）。

### 5. 备注
- 清仓后持仓份额置 0（记录仍保留），交易记录面板「已清仓」标签依赖 `holdingCodes.has(code)`（来自 holdingStore，含 0 份额记录），故清仓后不一定显示「已清仓」标签——属既有行为，未改动其判定逻辑（如需清仓即从持仓列表移除可另议）。
- Portfolio.vue 长按 handler 为空，无交易弹窗，本次未涉及。

## 清仓增强：按比例（1/2 · 1/3 · 1/4）+ 已清仓标记修复

### 1. 需求
- 清仓里加按比例选项：全清 / 1/2 / 1/3 / 1/4（用户原话「2分支1 3分之一 4分之一」，按 1/2、1/3、1/4 实现）。
- 清仓后在「交易记录」要能看到这笔记录，并标记「已清仓」。

### 2. 按比例清仓实现（Home.vue + PanoramaDashboard.vue 同步）
- `tradeFormData` 加 `clearRatio: number`（默认 1=全清）。
- 新增 `setClearRatio(r)` + 常量 `CLEAR_RATIOS = [{1,'全清'},{0.5,'1/2'},{1/3,'1/3'},{0.25,'1/4'}]`，清仓 tab 下渲染比例按钮（v-for）。
- `fillClearAmount()`：`shares = ratio>=1 ? total : round(total*ratio*100)/100`，按 `shares*净值` 自动带出金额。
- `submitTrade` 清仓分支：`sellShares = ratio>=1 ? total : round(...)`；`cur.shares = max(0, cur.shares - sellShares)`（全清→0，按比例→留剩余）。
- 预览/确认文案用 `clearRatioLabel()`（全清/1/2/1/3/1/4），不再显示难看的 `0.3333...`。

### 3. 「已清仓」标记修复（关键）
- 原 `groupedTrades` 判定 `isCleared = !holdingCodes.has(code)`：清仓后持仓记录仍在（shares=0），所以不显示「已清仓」——这正是用户质疑的点。
- 改为：`remaining = holdingShares.get(code)`；`isCleared = remaining===undefined || remaining===0 || !holdingCodes.has(code)`。
- 同步修改两处：`PanoramaDashboard.vue` 的 `groupedTrades`（约 L522）与 `TradeCenter.vue` 的 `groupedTrades`（约 L296）。两者都会因此正确显示「已清仓」标签与置后排序。
- 效果：全清（ratio>=1）后持仓归 0 → 交易记录自动显示「已清仓」；按比例（1/2 等）仍有剩余份额 → 不误标已清仓。

### 4. 关联交易记录
- 清仓提交的是 `createTrade({type:'sell', ...})`，交易记录本就会写入并在「交易记录」面板（全景 + TradeCenter）可见，无需额外处理；卖出点照常由 `getTradesByCode` 在 K 线自动标记。

### 5. 校验
- `npx vue-tsc -b` 通过（EXIT 0）。

### 6. 备注
- 仅改了「已清仓」判定，不影响其它持仓逻辑；0 份额持仓仍留在列表（可手动删除）。
- CSS：Home 加 `.clear-ratio-row/.clear-ratio-btn`，Panorama 加 `.pa-clear-ratio/.pa-clear-ratio-btn`（红=选中，与卖出同色）。

## 全景大屏星标K线：持仓卡内联星星切换（去掉长按菜单星标按钮）

### 1. 需求
- 原：全景大屏靠长按卡片 → 按钮菜单的「星标/取消星标」来控制谁进星标K线，太麻烦。
- 改：长按菜单去掉星标按钮；在左侧 Portfolio 持仓列表每只基金**名称右侧**加一颗星星，点击切换（类似手机端星标K线图表）：实心红=已星标，空心红边框=未星标。

### 2. 实现（PanoramaDashboard.vue）
- 长按 action bar 删除「星标/取消星标」按钮（原 `handleActionStar` 调用处）。
- 删除旧 `handleActionStar`，新增 `toggleStar(fund)`：`isStarred(code)?removeStarredFund:addStarredFund(code, starMetaFromFund(fund))` + toast。
- 持仓卡 `.fm-row-top` 名称后插入 `<span class="fm-star" :class="{starred: isStarred(fund.code)}" @click.stop="toggleStar(fund)">`，内嵌 SVG 五角星（实心/空心靠 class 切换）。
- CSS `.fm-star`：未星标=空心红边框（`fill:none;stroke:#f6465d`），星标=实心红（`fill:#f6465d`）；点击有缩放反馈。

### 3. 响应式（关键）
- `isStarredFund` 读 localStorage 非响应式，直接放模板点击后不重绘。改为维护响应式 `starredCodes = ref(new Set(getStarredFunds()))` + `isStarred(code)` 辅助函数。
- 监听 `window` 的 `starred-funds-changed`（storage 写星标后会广播）→ `refreshStarredCodes()` 即时刷新；`toggleStar` 里也主动 `refreshStarredCodes()`。onUnmounted 移除监听。
- `addStarredFund/removeStarredFund` → `writeStarredRaw` 会 dispatch `starred-funds-changed`，故星标K线面板（StarKLinePanel 监听该事件）会同步重读，无需额外处理。

### 4. 清理
- 旧 `handleActionStar` 不再被引用，删除；`isStarredFund` 在本文件不再使用，从 import 移除（避免 noUnusedLocals 报错）。`starMetaFromFund` 仍被 `toggleStar` 使用，保留。

### 5. 校验
- `npx vue-tsc -b` 通过（EXIT 0）。

### 6. 备注
- 范围：仅全景大屏左列 Portfolio 持仓卡加星星；量化观察列表、Home 长按菜单未动（用户只指全景）。
- 星标K线第二列随 `starred-funds-changed` 自动增删，体验和手机端一致。
