## 梳理：净值是否更新的判断链路（仅分析，未改代码）

用户问 `navIsCurrent` 是否替代了进度条用的 `isUpdated`。结论：**不是替代，是同一个公式的两份独立拷贝**。

- `isUpdated`（holding 上的持久化字段）：`holding.ts:267-272` 在 `updateHoldingWithAccurateData` 里**重算**并 `saveHoldings()` 落盘。进度条（Home.vue:1150 / PanoramaDashboard.vue:60）、Holding.vue:1306 的「已更新/未更新」标签、FundGridItem.vue:126 的名称配色都读它。
- `navIsCurrent`（API 返回值的瞬时字段）：`fundFast.ts` 内部 `isNavUpdated`，只服务 Detail.vue / TradeCenter.vue 的「恢复今日交易为 estimated」guard。
- 两者**互不通信**，进度条不读 `navIsCurrent`。

完整链路：`initHoldings()` → `refreshEstimates()` → 按 `!h.isUpdated` 过滤出 staleHoldings 才调 `fetchFundAccurateData`；已更新的走合成 data 快路径直接回灌 `updateHoldingWithAccurateData`（该函数内部又用合成 data 的 `valueDate` 重算 isUpdated，所以跨天能自校正，不会永久卡在 true）。

发现的重复/隐患（未修，待用户决定）：
1. 同一公式两份实现（`fundFast.ts:1696` vs `holding.ts:267`）。
2. `getTradingDateStr` 也是两份逐字相同的私有实现（`fundFast.ts:13` / `holding.ts:12`，逻辑一致所以暂无行为差异）。
3. `updateHoldingWithAccurateData` 不能简单改成直接信任 `data.navIsCurrent`：refreshEstimates 的快路径传的是自己合成的 data（navIsCurrent 恒为 true），会变成「自己证明自己」、永远维持已更新。
4. `currentValue <= 0` 早退分支（holding.ts:249）不会更新 `isUpdated`，保留旧值。
5. `isUpdated` 是运行时字段，本地导出和 Gist 备份时都被剔除（Holding.vue:435 / 664）。

## 已重构：抽出 utils/navDate.ts（用户确认）

新建 `src/utils/navDate.ts`，收敛两份重复：

- `getTradingDateStr(date?)` —— 原先在 `fundFast.ts:13` 和 `holding.ts:12` 各有一份逐字相同的私有实现，现只保留一份（早于 9:00 归到前一自然日的逻辑不变；内部改用 `target` 局部变量，不再重赋值入参）。

## 估值接口辨析（用户问 fetchFundEstimateFast 是不是废了）

结论：**没废，它就是用户记忆里「自己根据重仓股算估值」的那个函数**。两套估值 API 别搞混：

- `fetchFundEstimate`（`src/api/fund.ts:83`）—— **这才是「接口拿估值」**，走天天基金 JSONP `fundgz.1234567.com.cn/js/{code}.js`。仍被 `Holding.vue:263`、`ScreenshotImport.vue:326` 使用（这俩其实只取它的 `dwjz` 公布净值，不取 `gsz` 估值）。
- `fetchFundEstimateFast`（`src/api/fundFast.ts:269`）—— **自算估值**：`fetchTopHoldings()` 拉前10重仓股（权重+涨跌幅）→ 加权 `weightedChange/100` 得 `estimatedChange` → `prevNav * (1 + change/100)` 得估算净值。QDII 额外加 `getFXAdjustment()` 汇率调整；ETF 走等权平均。非交易时间直接返回 `persistCache` 的缓存，没有缓存就 throw（被 `fetchFundAccurateData` 的 `.catch(() => null)` 兜住 → estimate=0 → 回退净值）。

顺带清掉的死代码：
1. `Detail.vue:11` 只 import 了 `fetchFundEstimateFast` 从未调用 → 已删。
2. `fetchFundEstimatesBatch`（`fundFast.ts:553`）全项目只有定义、零调用 → **已删**。`vue-tsc -b` 通过。
