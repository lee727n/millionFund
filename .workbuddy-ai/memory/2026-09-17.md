## Request 20：全景大屏刷新按钮旁加「倒计时 + 自动刷新开关」

用户要在全景页右上角刷新按钮（↻）旁边加两样：① 距下次自动刷新还有多少秒（实时倒计时）；② 一个手动控制自动刷新开关的按钮。

### 改法（都在 `src/views/PanoramaDashboard.vue`）

- 顶部状态：`const AUTO_REFRESH_SECONDS = 60; const autoRefreshEnabled = ref(true); const countdown = ref(60)`。
- `tickCountdown()`：1 秒级，自动刷新开着时 `countdown--`，归零触发 `refreshAll(false)` 并复位到 60；关着时直接 return（冻结）。
- `toggleAutoRefresh()`：翻转 `autoRefreshEnabled`，开→`countdown=60`+toast「自动刷新已开启」，关→toast「已关闭」。
- `refreshAll()` 开头重置 `countdown.value = 60`（手动刷新也复位倒计时）。
- **生命周期**：原来 `setInterval(refreshAll, 60000)` 改成 `setInterval(tickCountdown, 1000)`，倒计时驱动自动刷新；`onUnmounted` 清 `refreshTimer`（变量名沿用）。
- 模板：在 ↻ 前加 `[自动刷新开关 button(.auto-refresh-toggle, is-on=开启)] [倒计时 span.refresh-countdown，开显示 \`{countdown}s\` / 关显示"已停"] [↻]`。
- CSS：`.refresh-countdown` 等宽字体、`min-width:36px` 防抖动；`.off` 减透明度；开关复用 `.top-icon-btn.is-on` 蓝色高亮。

`npx vue-tsc -b` 通过（exit 0）。
